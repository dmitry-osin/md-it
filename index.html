03 / НАЧНИТЕ С ПЕРВОЙ СТРАНИЦЫ

Ваша следующая заметка — здесь.

Версия 0.1.0 подготовлена к выпуску. Подтверждённой ссылки на Chrome Web Store пока нет.

1

Установите расширение

Получите подготовленную сборку у автора и загрузите её в Chrome. Подробная инструкция — ниже.

2

Откройте нужную страницу

Закрепите иконку Markdown-It на панели Chrome, нажмите её и выберите источник содержимого.

3

Заберите Markdown

Нажмите «Копировать Markdown», «Скачать .md» или откройте Preview, чтобы проверить результат.

Как установить подготовленную сборку вручную

Запросите сборку версии 0.1.0 у автора: d@osin.pro. Файлы расширения на этом сайте не размещены.

  1. Распакуйте полученный архив в постоянную папку.
  2. Откройте в адресной строке Chrome chrome://extensions и включите «Режим разработчика».
  3. Нажмите «Загрузить распакованное расширение» и выберите папку, содержащую manifest.json.
  4. В меню расширений Chrome закрепите Markdown-It. Затем откройте обычную веб-страницу и нажмите иконку.

Папка установленного расширения должна оставаться на устройстве. Для обновления распакованной сборки замените файлы и нажмите «Обновить» на её карточке.

ПОЛЕЗНО ЗНАТЬ

Несколько деталей.

Что умеет расширение и где есть ограничения.

На каких страницах работает Markdown-It?

На обычных веб-страницах, к которым Chrome разрешает доступ после нажатия иконки. На защищённых страницах браузера, например chrome://, конвертация недоступна. Содержимое документов во вложенных iframe не читается.

Сохранится ли всё оформление страницы?

Markdown сохраняет структуру содержимого, а не точный внешний вид сайта. Поддерживаются заголовки, ссылки, списки, код и таблицы. Сложные таблицы и неподдерживаемое оформление могут использовать очищенный HTML; особенности конвертации отражаются в диагностике. Правила сайта могут требовать обновления после изменения его вёрстки.

Почему в Preview не видны изображения?

Удалённые изображения заблокированы по умолчанию. Нажмите «Загрузить изображения», чтобы разрешить запросы к их исходным сайтам только в текущем Preview. Эти сайты получают обычные данные запроса, включая ваш IP-адрес и URL изображения; referrer не отправляется.

Что делать, если копирование не сработало?

Браузер может отказать в доступе к системному буферу обмена. Откройте Preview для проверки результата или воспользуйтесь «Скачать .md».

Можно перенести настройки на другое устройство?

Да, экспортируйте конфигурацию локальным файлом и импортируйте её на другом устройстве. Автоматической облачной синхронизации и фонового обхода сайтов нет. Расширение работает с выбранной вами текущей страницей по вашему действию.
