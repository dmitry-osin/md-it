# Проверка сайта Markdown-It

Дата: 15.10.2026. Проверено локально, через HTTP, с рабочим префиксом `/md-it/` в браузере Codex (Chromium). Публичная публикация не выполнялась.

## Автоматическая доступность магазина

По уточнённому запросу автора сайт автоматически скрывает кнопки Chrome Web Store, пока карточка ожидает публикации. После положительной проверки показывает установку. Обе локали, главная и CTA страницы политики используют общий `assets/store-status.json`.

- Проверка магазина испытана на настоящих HTTP-ответах: неопубликованная карточка Markdown-It и опубликованная Google Translate возвращают HTTP 200, но корректно распознаются как `pending` и `published` по содержимому. Живой запуск `scripts/store_status.py` для Markdown-It подтвердил `pending`.
- 15 тестов стандартного unittest прошли: опубликованная/недоступная карточка, generic HTTP 200, неверный ID, script вместо кнопки, 403/429/5xx, consent, сохранение статуса при сбое, отсутствие лишнего деплоя и переходы в обе стороны.
- Расписание в workflow запускает проверку каждый час, на 17-й минуте. Плановая публикация происходит только при изменении статуса относительно опубликованного JSON. Для push и ручного запуска выполняется обычный деплой. При неизвестном результате сохраняется последнее подтверждённое состояние.
- Определение браузера отдельно проверено на 15 профилях: Chrome, Firefox, Edge, Opera, Brave, Chromium, Safari, Android, iOS, iPad с desktop user agent, сенсорный ПК и отсутствие client hints. Для Firefox, телефона и других браузеров подготовлены локальные QA-профили, исключённые из публикации. Это симуляция входных данных в Chromium, а не заявление о проверке самого расширения в Firefox или Safari.
- В браузере проверены оба состояния JSON: при `pending` на главной и странице политики нет видимых кнопок магазина; при `published` кнопки появляются, смена языка сохраняет состояние, предупреждение Firefox остаётся. Проверены 12 комбинаций языка/браузерного профиля/ширины 320 и 375 px: переполнения нет. Консоль без ошибок. После симуляции `assets/store-status.json` возвращён в реальный исходный статус `pending`.

Расписание GitHub и реальный deployment не запускались из этой сессии. Для включения автоматики владелец один раз публикует обновлённый workflow; далее ручные изменения статуса не нужны. Ограничения задержек и отключения расписания после 60 дней без активности описаны в README.

## Автоматические проверки

- `python scripts/check.py` — успешно. Проверены две страницы, уникальные ID, внутренние якоря, 57 ссылок и ресурсов, пары переводов, метаданные и атрибуты изображений.
- Все абзацы и заголовки обеих версий политики совпадают с локальным `PRIVACY.md` после нормализации пробелов. Сам `PRIVACY.md` скопирован побайтово из проекта расширения.
- `node --check assets/site.js` — успешно.
- HTTP 200 для главной, политики, CSS, JavaScript, обеих иконок, восьми скриншотов, robots и sitemap; типы содержимого соответствуют файлам.
- Запрос `/md-it/policy?lang=en` перенаправляется на `/md-it/policy/?lang=en`, затем возвращает политику. Аналогично проверен русский адрес.
- Основной PNG и все восемь скриншотов совпадают с оригиналами побайтово. Скриншоты имеют размер 1280×800; исходная PNG-иконка сохраняет RGBA и прозрачность.
- В публичных HTML нет абсолютных локальных путей. CSS/JS не подключают внешние ресурсы или шрифты. JavaScript запрашивает только JSON статуса с того же сайта; проверку магазина выполняет GitHub Actions.
- Workflow формирует Pages-артефакт по явному списку файлов сайта. Документация, проверки, `.qa`, конфигурация и исходный код расширения в него не входят.

## Браузерная проверка

- Главная и политика открыты на русском и английском; просмотрены скриншоты широкого экрана 1440×1000 и мобильного 375×812.
- Дополнительно измерены обе страницы и обе локали на ширинах 320, 768, 1024, 1920 px. Найденное переполнение русской политики на 320 px устранено: настроены размер заголовка, перенос и компактная навигация. Повторная проверка: ширина документа равна доступной ширине окна.
- RU/EN меняет `html.lang`, заголовок вкладки, описание, видимые тексты, доступные названия, подписи картинок и набор скриншотов. Ссылки между страницами сохраняют выбранный язык; открытие адреса без `lang` использует сохранённый выбор.
- Галерея переключает Panel, Element Picker, Preview и Settings. Стрелки, Home/End меняют выбранную вкладку и фокус; видна синяя рамка фокуса. Изображения открываются по настоящим локальным ссылкам в исходном размере.
- Tab и Enter проверены для переключателя языка, основной кнопки, ссылки пропуска навигации и FAQ. FAQ раскрывается с клавиатуры; основная кнопка перемещает к инструкции установки.
- Прямая загрузка и перезагрузка политики работают после перенаправления каталога и сохраняют язык. Ссылки оглавления указывают на разделы выбранной языковой версии.
- Иконки и видимые скриншоты загружаются. Отложенная загрузка невидимых вкладок галереи ожидаема.
- В консоли страницы при проверенных переходах и переключениях ошибок и предупреждений не зафиксировано.
- В CSS предусмотрены `prefers-reduced-motion`, видимый фокус, адаптивные размеры и печать. В статическом HTML без JavaScript доступны русская главная, все изображения галереи и оба полных текста политики; это проверено по разметке.

## Скриншоты

Локальные снимки результата сохранены в исключённой из Git и публикации папке `.qa/`: главная и политика RU/EN для широкого и мобильного экрана, отдельный снимок галереи и первый экран. Скриншоты просмотрены при проверке; исходные изображения расширения не редактировались.

## Что остаётся владельцу

Создать коммит и отправить сайт в отдельный репозиторий, выбрать GitHub Actions в Settings → Pages и запустить workflow. После публикации проверить главную и `/md-it/policy` по HTTPS без авторизации, на обеих локалях. Локальная проверка не подтверждает настройки удалённого репозитория, успешность Actions или доступность публичных URL.

Инструкции и официальные источники GitHub приведены в README. При первоначальной подготовке URL магазина отсутствовал; затем автор предоставил его и подтвердил, что карточка ещё ожидает публикации. Текущий UI показывает ожидание и автоматически заменяет его кнопками магазина при подтверждённой доступности. Исходный проект расширения использовался только для чтения; коммит, push и публикация в рамках разработки не выполнялись.
